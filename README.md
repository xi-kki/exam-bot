# Exam Bot AI — Study Assistant

A pixel-perfect hero landing page for **Exam Bot AI (Examix)** — an AI study assistant — built as a single-file HTML + CSS + vanilla JS deliverable, per spec.

## What's inside

- `exam-bot-hero.html` — the complete hero page: fullscreen background video, edge-anchored layout, typewriter title, floating glass file cards, and center-out wipe upload button.
- `vercel.json` — routes the site root (`/`) to the hero page.
- `README.md` — this file.

## Run locally

No build step. Either open the file directly:

```
open exam-bot-hero.html   # macOS
start exam-bot-hero.html  # Windows
```

or serve it:

```
npx serve .
```

## Deploy a change to Vercel

```
vercel deploy --prod
```

## Roadmap

This repo is the starting hero shell; product functionality (real file upload, study flow) will be layered on top of it next.
